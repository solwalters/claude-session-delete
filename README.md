# Delete Session for Claude Code

> Unofficial. Not affiliated with or endorsed by Anthropic.

Adds a trash button to the Claude Code extension's sidebar, sessions list and
editor tabs. It deletes a session's transcript (`~/.claude/projects/<proj>/<id>.jsonl`
plus its folder), `file-history/<id>`, `session-env/<id>`, and any `todos`/`debug` files.

- **Editor tab button**: pre-selects the session in the active tab.
- **Sidebar / sessions list button**: lists this workspace's sessions, newest first.
- **Command Palette**: `Claude Code: Delete Session…` and `…(All Projects)…`.
- The globe button in the picker switches to all projects.

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `claudeSessionDelete.resetExtensionsOnDelete` | `always` | Claude Code only re-reads its session list on startup, so after a delete the extensions are reset (the extension host restarts). `ask` prompts after each delete; `never` leaves the deleted session listed until the next reload. Other Claude sessions resume where they left off when `claudeCode.continueAfterReload` is on, which is the default. |
| `claudeSessionDelete.useRecycleBin` | `true` | Move deleted files to the Recycle Bin instead of deleting them permanently. |

## How deletion works

Open editor tabs for deleted sessions are closed first so the CLI exits. A
closed session's CLI can write its title and cost metadata back to the deleted
transcript when it exits, so for 10 minutes afterwards any metadata-only stub is
removed. If real new messages appear instead, the session is still in use; you
get a warning and the messages are kept. A session that is live in the sidebar
can't be closed from here: switch the sidebar to another session, then delete it.

The archived list lives in the Claude extension's private storage, so a deleted
session's ID stays in it. A leftover ID there does nothing.

```
node test.js "C:\path\to\workspace"   # read-only smoke test
npx @vscode/vsce package
code --install-extension claude-session-delete-<version>.vsix
```

are in [PUBLISHING.md](PUBLISHING.md).
