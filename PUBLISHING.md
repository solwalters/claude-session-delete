# Publishing

How to release this extension to the VS Code Marketplace (and optionally Open VSX).

## First release

1. **Sign in** at <https://marketplace.visualstudio.com/manage> with a **personal**
   Microsoft account. The publisher belongs to whichever account creates it, so
   don't use a work account.
2. **Create a publisher** with the ID `solwalters`. It must match `"publisher"` in
   `package.json`. If the ID is taken, choose another, update `package.json`, and
   rebuild the package.
3. **Build the package**:
   ```
   npx @vscode/vsce package
   ```
   This writes `claude-session-delete-<version>.vsix` and should print no warnings.
4. On the manage page, choose **New extension → Visual Studio Code** and upload the
   `.vsix`.
5. **Wait for verification**, usually a few minutes. The listing then appears at
   <https://marketplace.visualstudio.com/items?itemName=solwalters.claude-session-delete>
   and in VS Code's Extensions view. Installing it from there replaces any locally
   installed `.vsix` with the same ID.

## Updates

1. Add an entry to `CHANGELOG.md`.
2. Bump the version (`patch` for fixes, `minor` for features):
   ```
   npm version patch --no-git-tag-version
   ```
3. Build the package:
   ```
   npx @vscode/vsce package
   ```
4. On the manage page, open the extension's **⋯** menu, choose **Update**, and
   upload the new `.vsix`.
5. Commit and push.

Publishing from the command line (`vsce publish`) needs an Azure DevOps personal
access token. Global tokens are retired on 1 December 2026, and the replacement
(`vsce publish --azure-credential`) needs Microsoft Entra ID setup. The web upload
avoids both.

## Optional

- **Screenshot or GIF**: put it in `images/` and reference it near the top of
  `README.md` with a relative path. The README is the listing page, and vsce turns
  relative image links into GitHub URLs, so push before uploading.
- **GitHub release**: tag the version and attach the `.vsix` so people can install
  it without the Marketplace:
  ```
  gh release create v<version> claude-session-delete-<version>.vsix --generate-notes
  ```
- **Open VSX** (used by Cursor, VSCodium, Windsurf): create an account at
  <https://open-vsx.org>, sign the publisher agreement, create the `solwalters`
  namespace, generate an access token, then:
  ```
  npx ovsx publish claude-session-delete-<version>.vsix -p <token>
  ```

## Icon

`images/icon.png` (128×128) is generated by `scripts/make-icon.ps1`. Edit the
colours or shapes there and rerun it on Windows:
```
pwsh scripts/make-icon.ps1
```
